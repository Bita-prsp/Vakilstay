# راهنمای توضیح کدهای پروژه اقامتگاه وکیل (VakilStay)
### بررسی فنی، آموزش بخش‌های مهم کد و آمادگی برای ارائه دانشگاهی

## ۱. مقدمه

در این فایل، بخش‌های مهم کدنویسی پروژه VakilStay بررسی می‌شوند. هدف این است که علاوه بر شناخت ساختار کلی پروژه، با نحوه عملکرد کدها و ارتباط بین HTML، CSS و JavaScript آشنا شویم.

این پروژه یک وب‌سایت فرانت‌اند برای معرفی اقامتگاه وکیل و راهنمای گردشگری شیراز است. در طراحی آن از HTML5، CSS3 و JavaScript استفاده شده و امکاناتی مانند فیلتر واحدهای اقامتی، جست‌وجوی جاذبه‌ها، نقشه تعاملی، تغییر زبان، پوسته روشن و تاریک، علاقه‌مندی‌ها و برنامه‌ریزی سفر پیاده‌سازی شده‌اند.

سه فایل اصلی پروژه عبارت‌اند از:

- `index.html`: ساختار صفحه
- `style.css`: طراحی ظاهری صفحه
- `script.js`: منطق و عملکرد امکانات سایت

# بخش اول: بررسی کدهای HTML

## ۲. ساختار اصلی سند HTML

در ابتدای فایل `index.html` کد زیر قرار دارد:

```html
<!doctype html>
<html lang="fa" dir="rtl">
<head>
```

### توضیح کد

- `<!doctype html>` به مرورگر اعلام می‌کند که سند از استاندارد HTML5 استفاده می‌کند.
- تگ `<html>` ریشه اصلی سند HTML است.
- ویژگی `lang="fa"` زبان اصلی صفحه را فارسی مشخص می‌کند.
- ویژگی `dir="rtl"` جهت نوشتار را راست‌به‌چپ تعیین می‌کند.
- بخش `<head>` اطلاعات و تنظیمات صفحه را در خود جای می‌دهد.

**نکته:** زبان و جهت صفحه دو مفهوم متفاوت‌اند. `lang` زبان سند را مشخص می‌کند، اما `dir` جهت نوشتار را تعیین می‌کند.

## ۳. تنظیمات اولیه صفحه

در بخش `head` کدهای زیر وجود دارند:

```html
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<meta name="theme-color" content="#14100f">
```

### توضیح کد

**`charset="utf-8"`**

برای پشتیبانی از نویسه‌های مختلف، از جمله حروف فارسی و انگلیسی، استفاده می‌شود.

**`name="viewport"`**

باعث می‌شود عرض صفحه با عرض دستگاه هماهنگ شود و مرورگر صفحه را برای نمایش موبایل به شکل مناسبی تنظیم کند.

**`name="theme-color"`**

رنگ پیشنهادی رابط مرورگر در بخش‌هایی که از این قابلیت پشتیبانی می‌کنند را مشخص می‌کند.

## ۴. اتصال فایل‌های CSS و JavaScript

در فایل HTML، فایل استایل و کتابخانه نقشه به این شکل متصل شده‌اند:

```html
<link rel="stylesheet" href="style.css">
```

این دستور فایل CSS پروژه را به سند HTML متصل می‌کند تا ظاهر عناصر صفحه طبق قوانین تعریف‌شده در آن نمایش داده شود.

همچنین کد زیر کتابخانه Leaflet را بارگذاری می‌کند:

```html
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"
        defer crossorigin=""></script>
```

- `src` آدرس فایل JavaScript خارجی را مشخص می‌کند.
- `defer` اجرای اسکریپت را تا زمان تجزیه HTML به تعویق می‌اندازد.
- `crossorigin` تنظیم مربوط به درخواست بین‌مبدأ را مشخص می‌کند.

فایل اصلی JavaScript پروژه نیز با استفاده از تگ `script` بارگذاری می‌شود.

**چرا از کتابخانه خارجی استفاده شده است؟**

ساخت یک نقشه تعاملی از ابتدا به کدنویسی زیادی نیاز دارد. Leaflet بسیاری از امکانات پایه نقشه را آماده فراهم می‌کند و توسعه‌دهنده می‌تواند آن را با داده‌های پروژه ترکیب کند.

## ۵. متاتگ‌های معرفی سایت

در بخش `head`، متاتگ‌هایی مانند `description`، `keywords` و اطلاعات Open Graph نیز تعریف شده‌اند.

برای مثال:

```html
<meta name="description"
      content="Plan your Shiraz stay with VakilStay: accommodation, local attractions, weather forecast, travel itineraries and practical visitor tips.">
```

این متاتگ توضیح کوتاهی درباره محتوای سایت ارائه می‌دهد و می‌تواند در نحوه معرفی صفحه در نتایج موتورهای جست‌وجو مؤثر باشد.

متاتگ‌های Open Graph نیز اطلاعاتی مانند عنوان، توضیحات و تصویر پیش‌نمایش سایت را هنگام اشتراک‌گذاری لینک در سرویس‌های سازگار مشخص می‌کنند.

## ۶. ساختار معنایی صفحه

در HTML از تگ‌هایی مانند `header`، `nav`، `main`، `section` و `footer` استفاده شده است.

برای نمونه:

```html
<header class="header" id="header">
```

هدر بخش بالایی سایت را مشخص می‌کند.

```html
<nav class="nav" id="mainNav" aria-label="منوی اصلی">
```

این بخش برای قرار دادن لینک‌های ناوبری سایت استفاده می‌شود.

```html
<main>
```

محتوای اصلی صفحه را مشخص می‌کند.

```html
<section class="hero" id="home">
```

بخش اصلی یا Hero سایت را تعریف می‌کند؛ همان بخشی که کاربر در ابتدای ورود مشاهده می‌کند.

استفاده از عناصر معنایی به خوانایی ساختار HTML و درک بهتر بخش‌های صفحه توسط ابزارهای کمکی کمک می‌کند.

## ۷. شناسه‌ها و کلاس‌ها

در کدهای HTML، ویژگی‌های `id` و `class` کاربرد زیادی دارند.

برای مثال:

```html
<section class="hero" id="home">
```

- `class="hero"` برای اعمال استایل‌های مربوط به بخش اصلی استفاده می‌شود.
- `id="home"` شناسه این بخش است و برای لینک داخلی یا انتخاب عنصر با JavaScript کاربرد دارد.

تفاوت مهم آن‌ها این است که یک کلاس می‌تواند روی چندین عنصر استفاده شود، اما هر `id` باید در همان سند یکتا باشد.

## ۸. آیکون‌های SVG

در پروژه، مجموعه‌ای از آیکون‌ها با استفاده از SVG تعریف شده‌اند.

نمونه:

```html
<symbol id="i-heart" viewBox="0 0 24 24">
  <path d="M20.8 8.8c0 5.4-8.8 10.5-8.8 10.5S3.2 14.2 3.2 8.8a4.8 4.8 0 0 1 8-3.6 4.8 4.8 0 0 1 8 3.6Z"/>
</symbol>
```

این کد شکل یک آیکون قلب را تعریف می‌کند.

برای نمایش آن در بخش دیگری از صفحه از تگ `use` استفاده می‌شود:

```html
<svg class="icon">
  <use href="#i-heart"></use>
</svg>
```

در این روش، شکل آیکون یک بار تعریف می‌شود و در قسمت‌های مختلف سایت قابل استفاده است.

مزیت SVG این است که آیکون‌ها در اندازه‌های مختلف وضوح مناسبی دارند و می‌توان رنگ و ظاهر آن‌ها را با CSS کنترل کرد.

# بخش دوم: بررسی کدهای CSS

## ۹. تعریف متغیرهای CSS

در ابتدای فایل `style.css` متغیرهای رنگ، سایه و اندازه تعریف شده‌اند:

```css
:root {
  --bg: #14100f;
  --bg2: #1d1513;
  --surface: #241916;
  --text: #f7efe6;
  --gold: #d9ad62;
  --container: 1200px;
}
```

### توضیح کد

- `:root` به عنصر ریشه سند اشاره می‌کند.
- متغیرهای CSS با دو خط تیره `--` شروع می‌شوند.
- `--bg` رنگ پس‌زمینه اصلی را نگه می‌دارد.
- `--text` رنگ متن را مشخص می‌کند.
- `--gold` رنگ طلایی اصلی رابط کاربری است.
- `--container` حداکثر عرض در نظر گرفته‌شده برای محتوای صفحه را تعیین می‌کند.

برای استفاده از متغیرها در بخش‌های دیگر CSS، از `var()` استفاده می‌شود:

```css
body {
  background: var(--bg);
  color: var(--text);
}
```

### مزیت استفاده از متغیرها

اگر قرار باشد رنگ اصلی سایت تغییر کند، لازم نیست تمام قوانین CSS را جداگانه ویرایش کنیم. کافی است مقدار متغیر مربوط را تغییر دهیم.

## ۱۰. پیاده‌سازی پوسته روشن و تاریک

یکی از ویژگی‌های سایت امکان تغییر تم است.

در فایل CSS، رنگ‌های حالت روشن به این شکل تعریف شده‌اند:

```css
html[data-theme=light] {
  --bg: #f5ecdf;
  --bg2: #eadbc9;
  --surface: #fff8ef;
  --text: #38271c;
  --gold: #9f712b;
}
```

این selector زمانی اعمال می‌شود که عنصر `html` دارای ویژگی `data-theme="light"` باشد.

در نتیجه، مقدار متغیرهای رنگ تغییر می‌کند و بخش‌هایی از سایت که از این متغیرها استفاده می‌کنند، به‌صورت هماهنگ ظاهر روشن می‌گیرند.

این روش باعث می‌شود به‌جای تعریف جداگانه استایل تمام اجزای سایت برای هر پوسته، بتوان بخش زیادی از تغییرات را با تغییر متغیرها مدیریت کرد.

## ۱۱. تنظیم اندازه و چیدمان صفحه

در فایل CSS، کلاس `container` برای کنترل عرض محتوا استفاده شده است:

```css
.container {
  width: min(var(--container), calc(100% - 44px));
  margin-inline: auto;
}
```

### توضیح خط‌به‌خط

- `width` عرض عنصر را تعیین می‌کند.
- `min()` کوچک‌ترین مقدار بین دو مقدار داده‌شده را انتخاب می‌کند.
- `var(--container)` عرض حداکثری محتوا را مشخص می‌کند.
- `calc(100% - 44px)` عرض قابل استفاده صفحه را با در نظر گرفتن فاصله از دو طرف محاسبه می‌کند.
- `margin-inline: auto` فضای اطراف عنصر را در محور افقی تنظیم می‌کند و آن را در مرکز قرار می‌دهد.

این روش کمک می‌کند محتوا در صفحه‌های بزرگ بیش از حد کشیده نشود و در صفحه‌های کوچک نیز فضای کناری مناسبی داشته باشد.

## ۱۲. مدل جعبه‌ای CSS

در CSS پروژه از قانون زیر استفاده شده است:

```css
* {
  box-sizing: border-box;
}
```

علامت `*` به معنی انتخاب همه عناصر است.

با تنظیم `box-sizing: border-box`، عرض و ارتفاع تعیین‌شده برای عنصر شامل محتوای داخلی، فاصله داخلی و حاشیه مرزی آن می‌شود.

این تنظیم محاسبه اندازه عناصر را ساده‌تر می‌کند و در طراحی واکنش‌گرا مفید است.

## ۱۳. طراحی کارت‌ها و دکمه‌ها

در سایت کلاس‌هایی مانند موارد زیر وجود دارند:

- `.room-card`
- `.btn`
- `.btn-gold`
- `.btn-glass`
- `.icon-btn`

این کلاس‌ها برای ایجاد ظاهر یکپارچه در کارت‌ها و دکمه‌ها استفاده می‌شوند.

برای مثال، کلاس `.btn` می‌تواند اندازه، فاصله داخلی، گردی گوشه‌ها و نحوه قرارگیری متن و آیکون را کنترل کند. کلاس `.btn-gold` نیز ظاهر ویژه دکمه طلایی را تعیین می‌کند.

استفاده از کلاس‌های مشترک باعث می‌شود اجزای مشابه در سراسر سایت ظاهر هماهنگی داشته باشند.

## ۱۴. طراحی واکنش‌گرا

طراحی واکنش‌گرا یعنی چیدمان صفحه براساس اندازه صفحه نمایش تغییر کند.

در این روش می‌توان با Media Queryها، اندازه فونت، فاصله‌ها، تعداد ستون‌ها و نحوه نمایش منو را برای موبایل یا رایانه تغییر داد.

برای نمونه، یک قانون واکنش‌گرا می‌تواند به این شکل باشد:

```css
@media (max-width: 768px) {
  /* قوانین مربوط به صفحه‌های کوچک */
}
```

این نمونه شکل کلی یک Media Query است. قوانین داخل آن زمانی اعمال می‌شوند که عرض صفحه حداکثر ۷۶۸ پیکسل باشد.

در پروژه VakilStay، طراحی واکنش‌گرا برای حفظ خوانایی و امکان استفاده از امکانات سایت در صفحه‌های کوچک اهمیت دارد.

## ۱۵. انیمیشن و افکت‌های بصری

در CSS پروژه از ویژگی‌هایی مانند `transition`، `transform`، `opacity` و `filter` استفاده شده است.

برای مثال، `transition` تغییرات ظاهری را تدریجی می‌کند و `transform` می‌تواند عنصر را جابه‌جا یا بزرگ و کوچک کند.

این ویژگی‌ها در افکت‌های hover، ظاهر دکمه‌ها، انیمیشن ورود بخش‌ها و جلوه‌های بصری سایت کاربرد دارند.

# بخش سوم: بررسی کدهای JavaScript

## ۱۶. قرار دادن کد در محدوده مستقل

ابتدای `script.js` به این شکل است:

```javascript
(() => {
  "use strict";

  const $ = (s, r = document) => r.querySelector(s);
  const $$ = (s, r = document) => [...r.querySelectorAll(s)];

})();
```

این الگو یک تابع را تعریف می‌کند و بلافاصله اجرا می‌کند. به این روش IIFE گفته می‌شود.

### چرا از این روش استفاده شده است؟

کدهای داخل تابع در محدوده محلی قرار می‌گیرند. در نتیجه، متغیرها و توابع پروژه بدون نیاز به تعریف متغیرهای سراسری متعدد مدیریت می‌شوند.

دستور `"use strict"` نیز حالت سخت‌گیرانه JavaScript را فعال می‌کند تا برخی خطاهای برنامه‌نویسی زودتر شناسایی شوند.

## ۱۷. توابع کمکی برای انتخاب عناصر

دو تابع زیر در ابتدای فایل تعریف شده‌اند:

```javascript
const $ = (s, r = document) => r.querySelector(s);

const $$ = (s, r = document) =>
  [...r.querySelectorAll(s)];
```

### تابع اول

`$()` یک عنصر مطابق انتخابگر CSS را پیدا می‌کند.

برای مثال:

```javascript
$("#roomsGrid")
```

عنصری را پیدا می‌کند که شناسه آن `roomsGrid` است.

### تابع دوم

`$$()` همه عناصر مطابق انتخابگر را پیدا می‌کند و نتیجه را به آرایه تبدیل می‌کند.

برای مثال:

```javascript
$$(".filter-pill")
```

همه عناصر دارای کلاس `filter-pill` را انتخاب می‌کند.

**مزیت این دو تابع:** کوتاه‌تر شدن کد و خواناتر شدن دستورات انتخاب عناصر HTML.

## ۱۸. تبدیل اعداد برای نمایش فارسی

در پروژه تابع زیر وجود دارد:

```javascript
let englishMode = false;

const fa = n =>
  englishMode
    ? String(n)
    : String(n).replace(/\d/g, d => "۰۱۲۳۴۵۶۷۸۹"[d]);
```

### توضیح کد

- `englishMode` مشخص می‌کند رابط در حالت انگلیسی است یا فارسی.
- `String(n)` مقدار ورودی را به رشته تبدیل می‌کند.
- عبارت منظم `/\d/g` تمام رقم‌های موجود در رشته را پیدا می‌کند.
- تابع `replace()` هر رقم انگلیسی را با رقم فارسی متناظر جایگزین می‌کند.

برای مثال، در حالت فارسی عدد `123` به `۱۲۳` تبدیل می‌شود.

در حالت انگلیسی، مقدار به همان شکل اصلی نمایش داده می‌شود.

## ۱۹. تعریف داده‌های جاذبه‌های گردشگری

اطلاعات جاذبه‌ها در آرایه‌ای به نام `locations` نگهداری می‌شوند.

هر عنصر آرایه یک شیء JavaScript است که اطلاعات یک مکان را در خود دارد.

نمونه:

```javascript
{
  id: "vakil",
  lat: 29.61645,
  lon: 52.54265,
  n: "01",
  name: "بازار وکیل",
  en: "VAKIL BAZAAR",
  category: "history",
  categoryName: "بازار و معماری",
  image: "assets/locations/vakil-bazaar.webp"
}
```

### کاربرد ویژگی‌ها

- `id`: شناسه داخلی مکان
- `lat`: عرض جغرافیایی
- `lon`: طول جغرافیایی
- `n`: شماره نمایشی مکان
- `name`: نام فارسی
- `en`: نام انگلیسی
- `category`: شناسه دسته‌بندی
- `categoryName`: نام دسته‌بندی
- `image`: مسیر تصویر مکان

این ساختار باعث می‌شود اطلاعات جاذبه‌ها از منطق نمایش آن‌ها جدا باشند. بنابراین می‌توان مکان جدیدی اضافه کرد و از توابع موجود برای نمایش، جست‌وجو و فیلتر کردن آن استفاده کرد.

## ۲۰. تعریف واحدهای اقامتی

آرایه `rooms` اطلاعات واحدهای اقامتگاه را نگهداری می‌کند.

برای نمونه:

```javascript
{
  id: "room-1",
  title: "واحد ۱",
  capacity: 4,
  badge: "خانوادگی",
  desc: "یک‌خوابه؛ مناسب خانواده و گروه کوچک.",
  img: "assets/rooms/room-1.webp",
  features: [
    "یک تخت دبل + سه تخت تکی",
    "آشپزخانه کامل",
    "تلویزیون و مبلمان"
  ],
  link: "https://www.jajiga.com/r/3hwx/dr",
  style: "room-gold"
}
```

### توضیح

- `capacity` ظرفیت واحد را مشخص می‌کند.
- `features` آرایه‌ای از امکانات واحد است.
- `link` نشانی صفحه رزرو مربوط به واحد را نگه می‌دارد.
- `style` کلاس ظاهری مورد استفاده برای کارت را مشخص می‌کند.

با ذخیره اطلاعات در آرایه، برای هر واحد نیازی به نوشتن جداگانه تمام منطق نمایش نیست؛ تابع رندر از داده‌ها برای ساخت کارت استفاده می‌کند.

## ۲۱. ساخت کارت‌های واحدهای اقامتی

تابع `renderRooms()` مسئول نمایش واحدهای اقامتی است.

یکی از قسمت‌های مهم آن:

```javascript
const data = rooms.filter(
  r => roomCapacity === "all" ||
       r.capacity === Number(roomCapacity)
);
```

### توضیح

تابع `filter()` واحدهایی را انتخاب می‌کند که با فیلتر ظرفیت مطابقت داشته باشند.

اگر مقدار `roomCapacity` برابر `"all"` باشد، همه واحدها نمایش داده می‌شوند. در غیر این صورت، ظرفیت هر واحد با مقدار انتخاب‌شده مقایسه می‌شود.

`Number(roomCapacity)` مقدار انتخاب‌شده را به عدد تبدیل می‌کند تا مقایسه با ویژگی عددی `capacity` انجام شود.

سپس اطلاعات واحدها با استفاده از `map()` به ساختار HTML کارت‌ها تبدیل می‌شود و در عنصر `roomsGrid` قرار می‌گیرد.

### تفاوت `filter()` و `map()`

- `filter()` برای انتخاب موارد مطابق شرط استفاده می‌شود.
- `map()` هر عضو آرایه را به یک مقدار یا ساختار جدید تبدیل می‌کند.

## ۲۲. جست‌وجو و فیلتر جاذبه‌ها

تابع `getFilteredLocations()` اطلاعات جاذبه‌ها را براساس عبارت جست‌وجو، دسته‌بندی انتخاب‌شده و وضعیت علاقه‌مندی فیلتر می‌کند.

قسمتی از کد:

```javascript
function getFilteredLocations() {
  const query = (
    $("#locationSearch")?.value || ""
  ).trim().toLocaleLowerCase(
    englishMode ? "en" : "fa"
  );

  return locations.filter(l => {
    const cat =
      activeCategory === "all" ||
      l.category === activeCategory;

    const saved =
      !onlySaved || savedItems.includes(l.id);

    // بررسی عبارت جست‌وجو و سایر شرایط
  });
}
```

### توضیح

- مقدار ورودی جست‌وجو خوانده می‌شود.
- `trim()` فاصله‌های ابتدا و انتهای متن را حذف می‌کند.
- `toLocaleLowerCase()` حروف را برای جست‌وجوی بدون حساسیت به بزرگی و کوچکی حروف انگلیسی یکدست می‌کند.
- `activeCategory` دسته‌بندی انتخاب‌شده را نگهداری می‌کند.
- `onlySaved` مشخص می‌کند که فقط مکان‌های ذخیره‌شده نمایش داده شوند یا خیر.
- `savedItems.includes(l.id)` بررسی می‌کند که شناسه مکان در فهرست علاقه‌مندی‌ها وجود دارد یا نه.

در ادامه تابع، عبارت جست‌وجو با اطلاعات مختلف هر مکان مقایسه می‌شود؛ از جمله نام، دسته‌بندی، برچسب‌ها و توضیحات.

نتیجه این است که کاربر می‌تواند مکان‌ها را با ترکیبی از جست‌وجو، دسته‌بندی و علاقه‌مندی‌ها محدود کند.

## ۲۳. مدیریت علاقه‌مندی‌ها

در پروژه، اطلاعات علاقه‌مندی‌ها در متغیر `savedItems` نگهداری می‌شوند.

هنگامی که کاربر دکمه ذخیره یک واحد را انتخاب می‌کند، کد بررسی می‌کند که شناسه آن واحد قبلاً در آرایه وجود داشته است یا خیر.

```javascript
savedItems = savedItems.includes(id)
  ? savedItems.filter(x => x !== id)
  : [...savedItems, id];
```

### توضیح

اگر شناسه از قبل وجود داشته باشد، با `filter()` از آرایه حذف می‌شود.

اگر وجود نداشته باشد، با استفاده از عملگر Spread یعنی `...` یک آرایه جدید ساخته می‌شود و شناسه جدید به آن اضافه می‌شود.

این روش باعث می‌شود یک دکمه هم برای اضافه کردن علاقه‌مندی و هم برای حذف آن کاربرد داشته باشد.

## ۲۴. ذخیره اطلاعات با Local Storage

در پروژه، کلیدهای ذخیره‌سازی به شکل زیر تعریف شده‌اند:

```javascript
const STORAGE = {
  theme: "vakilstay:theme-v3",
  saved: "vakilstay:saved-v3",
  trip: "vakilstay:trip-v3"
};
```

این کلیدها برای ذخیره تنظیمات پوسته، علاقه‌مندی‌ها و برنامه سفر استفاده می‌شوند.

تابع خواندن اطلاعات:

```javascript
function readJSON(k, d) {
  try {
    return JSON.parse(
      localStorage.getItem(k)
    ) ?? d;
  } catch {
    return d;
  }
}
```

تابع ذخیره اطلاعات:

```javascript
function storeJSON(k, v) {
  try {
    localStorage.setItem(
      k,
      JSON.stringify(v)
    );
  } catch {}
}
```

### توضیح توابع

- `getItem()` اطلاعات ذخیره‌شده را براساس کلید می‌خواند.
- `setItem()` اطلاعات را در مرورگر ذخیره می‌کند.
- `JSON.stringify()` آرایه یا شیء را به متن JSON تبدیل می‌کند.
- `JSON.parse()` متن JSON را به مقدار JavaScript تبدیل می‌کند.
- `try/catch` از متوقف شدن اجرای برنامه در صورت بروز خطا در عملیات ذخیره‌سازی جلوگیری می‌کند.

**نکته مهم:** Local Storage یک پایگاه داده مرکزی نیست. اطلاعات در مرورگر همان کاربر ذخیره می‌شوند و به‌صورت خودکار بین دستگاه‌های مختلف همگام‌سازی نمی‌شوند.

## ۲۵. تغییر پوسته روشن و تاریک

تابع `applyTheme()` پوسته ذخیره‌شده را هنگام راه‌اندازی بازیابی می‌کند.

تابع `toggleTheme()` نیز برای تغییر پوسته استفاده می‌شود:

```javascript
function toggleTheme() {
  const next =
    document.documentElement.dataset.theme === "dark"
      ? "light"
      : "dark";

  document.documentElement.dataset.theme = next;

  try {
    localStorage.setItem(
      "vakilstay:theme-v3",
      next
    );
  } catch {}

  const b = $("#themeToggle");

  if (b) {
    b.innerHTML = icons(
      next === "dark" ? "i-sun" : "i-moon"
    );
  }
}
```

### مراحل عملکرد

۱. پوسته فعلی خوانده می‌شود.

۲. اگر پوسته تاریک باشد، حالت روشن انتخاب می‌شود و برعکس.

۳. مقدار جدید در ویژگی `data-theme` عنصر HTML قرار می‌گیرد.

۴. انتخاب جدید در Local Storage ذخیره می‌شود.

۵. آیکون دکمه تغییر پوسته به‌روزرسانی می‌شود.

به این ترتیب، JavaScript وضعیت پوسته را تغییر می‌دهد و CSS براساس آن ظاهر جدید را اعمال می‌کند.

## ۲۶. ایجاد نقشه تعاملی با Leaflet

کتابخانه Leaflet برای نمایش نقشه و نشانگرهای جغرافیایی استفاده شده است.

ابتدا مختصات اقامتگاه در ثابت `STAY_POINT` تعریف می‌شوند:

const STAY_POINT = {

سپس تابع `initLocationMap()` نقشه را در عنصر HTML مربوط ایجاد می‌کند.

L.map(mapElement)

## ۲۸. برنامه‌ریزی سفر و مدیریت مقصدها

شناسه مکان‌های انتخاب‌شده برای برنامه سفر در آرایه `tripIds` نگهداری می‌شوند.

تابع `setupTrip()` رویدادهای مربوط به برنامه سفر را تنظیم می‌کند؛ از جمله افزودن مکان، پاک کردن فهرست، کپی کردن برنامه و باز کردن مسیر.

در تابع `openMultiRoute()` ابتدا مکان‌های انتخاب‌شده از آرایه `locations` پیدا می‌شوند:

```javascript
const items = tripIds
  .map(id => locations.find(x => x.id === id))
  .filter(Boolean);
```

### توضیح

- `map()` شناسه‌ها را به اطلاعات کامل مکان‌ها تبدیل می‌کند.
- `find()` مکان مطابق شناسه را پیدا می‌کند.
- `filter(Boolean)` مقادیر نامعتبر یا `undefined` را حذف می‌کند.

اگر هیچ مکانی انتخاب نشده باشد، پیام راهنما نمایش داده می‌شود. اگر یک مکان انتخاب شده باشد، لینک همان مکان باز می‌شود. در صورت انتخاب چند مکان، لینک مسیر چندمقصدی Google Maps ساخته می‌شود.

## ۳۱. نمایش تدریجی عناصر با IntersectionObserver

تابع `setupReveal()` از `IntersectionObserver` استفاده می‌کند تا عناصر دارای کلاس `reveal` هنگام ورود به محدوده قابل مشاهده، کلاس `visible` دریافت کنند.

نمونه‌ای از منطق آن:

```javascript
const io = new IntersectionObserver(
  entries => entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add("visible");
      io.unobserve(entry.target);
    }
  }),
  { threshold: 0.1 }
);
```

### توضیح

- `IntersectionObserver` تغییر وضعیت قابل مشاهده بودن عناصر را بررسی می‌کند.
- `isIntersecting` مشخص می‌کند که عنصر وارد محدوده مشاهده شده است یا خیر.
- `classList.add("visible")` کلاس موردنیاز برای فعال شدن استایل را اضافه می‌کند.
- `unobserve()` مشاهده عنصر را پس از اجرای این رفتار متوقف می‌کند.

در نتیجه، عناصر می‌توانند هنگام اسکرول کاربر به‌صورت تدریجی ظاهر شوند.

## ۳۲. مدیریت پنجره‌های بازشو و گالری

این روش تجربه مشاهده تصاویر را ساده‌تر می‌کند، بدون اینکه کاربر مجبور باشد برای هر تصویر به صفحه دیگری برود.

## ۳۵. فایل Manifest و Service Worker

علاوه بر فایل‌های اصلی، پروژه شامل `manifest.webmanifest` و `sw.js` نیز هست.

### فایل `manifest.webmanifest`

این فایل اطلاعاتی درباره وب‌اپ، مانند نام، عنوان کوتاه، آیکون‌ها و تنظیمات نمایش را در اختیار مرورگر قرار می‌دهد.

این اطلاعات برای مرورگرهایی که قابلیت نصب وب‌اپ را پشتیبانی می‌کنند، مفید است.

### فایل `sw.js`

این فایل مربوط به Service Worker است؛ اسکریپتی که مرورگر می‌تواند در محدوده مشخصی از قابلیت‌های وب‌اپ اجرا کند.

Service Worker می‌تواند برای مدیریت درخواست‌ها و کش کردن منابع استفاده شود. رفتار دقیق آن به پیاده‌سازی داخل فایل `sw.js` بستگی دارد.

**نکته:** وجود Manifest یا Service Worker به‌تنهایی به معنی پشتیبانی کامل از تمام قابلیت‌های آفلاین نیست؛ این موضوع به کد و منابعی بستگی دارد که واقعاً کش شده‌اند.

## ۳۶. یک مثال کامل از همکاری HTML، CSS و JavaScript

فرض کنیم کاربر می‌خواهد فقط واحدهای دو نفره را مشاهده کند.

### مرحله اول: HTML

HTML عنصر فیلتر و محل نمایش کارت‌های واحد را در صفحه قرار می‌دهد.

### مرحله دوم: CSS

CSS ظاهر دکمه‌های فیلتر و کارت‌های اقامتی را تعیین می‌کند.

### مرحله سوم: JavaScript

JavaScript رویداد کلیک روی فیلتر را دریافت می‌کند، مقدار ظرفیت انتخاب‌شده را می‌خواند و تابع `renderRooms()` را اجرا می‌کند.

این تابع آرایه `rooms` را فیلتر می‌کند و کارت‌های واحدهای مطابق را دوباره در صفحه قرار می‌دهد.

این مثال نشان می‌دهد که سه فناوری اصلی پروژه چگونه با یکدیگر همکاری می‌کنند.

## ۳۷. برای تغییر هر بخش باید سراغ کدام فایل بروم؟

| تغییر موردنظر | فایل یا بخش مناسب |
|---|---|
| تغییر ساختار بخش‌های صفحه | `index.html` |
| تغییر رنگ‌ها و ظاهر سایت | `style.css` |
| تغییر چیدمان موبایل | قوانین واکنش‌گرای `style.css` |
| تغییر اطلاعات واحدهای اقامت | آرایه `rooms` در `script.js` |
| افزودن جاذبه گردشگری | آرایه `locations` در `script.js` و افزودن تصویر مرتبط |
| تغییر فیلتر ظرفیت | توابع `setupRooms()` و `renderRooms()` |
| تغییر جست‌وجوی جاذبه‌ها | توابع `getFilteredLocations()` و رندر مکان‌ها |
| تغییر منطق علاقه‌مندی‌ها | متغیر `savedItems` و توابع مرتبط |

# بخش پنجم: سؤال‌های احتمالی استاد

## ۳۸. سؤال و جواب‌های فنی

**۱. تفاوت HTML، CSS و JavaScript چیست؟**

HTML ساختار صفحه را ایجاد می‌کند، CSS ظاهر و چیدمان را کنترل می‌کند و JavaScript رفتارهای تعاملی و تغییرات پویا را مدیریت می‌کند.

**۲. چرا اطلاعات واحدها و جاذبه‌ها در آرایه ذخیره شده‌اند؟**

چون داده‌ها از منطق نمایش جدا می‌شوند. این کار باعث می‌شود بتوان اطلاعات را مدیریت کرد و با توابع مشترک، کارت‌ها و فیلترها را ایجاد کرد.

**۳. تابع `renderRooms()` چه کاری انجام می‌دهد؟**

واحدهای اقامتی را براساس فیلتر انتخاب‌شده بررسی می‌کند، ساختار کارت‌های آن‌ها را می‌سازد و در محل مشخص‌شده در صفحه نمایش می‌دهد.

**۴. تفاوت `filter()` و `map()` چیست؟**

`filter()` اعضایی را که شرط مشخصی دارند انتخاب می‌کند؛ `map()` هر عضو را به یک مقدار یا ساختار جدید تبدیل می‌کند.

**۵. Local Storage چیست؟**

قابلیتی در مرورگر برای ذخیره داده‌های متنی به‌صورت محلی است. در این پروژه برای نگهداری تنظیمات پوسته، علاقه‌مندی‌ها و برنامه سفر استفاده می‌شود.

**۶. آیا Local Storage جایگزین پایگاه داده است؟**

خیر. داده‌های آن در مرورگر همان کاربر ذخیره می‌شوند و به‌صورت خودکار بین کاربران یا دستگاه‌های مختلف همگام‌سازی نمی‌شوند.

**۷. API چیست؟**

API رابطی برای ارتباط یک برنامه با سرویس یا نرم‌افزار دیگر است. در این پروژه، سرویس Open-Meteo برای دریافت اطلاعات آب‌وهوا استفاده می‌شود.

**۸. Leaflet چه تفاوتی با OpenStreetMap دارد؟**

Leaflet کتابخانه نمایش نقشه تعاملی است؛ OpenStreetMap منبع داده نقشه پایه مورد استفاده در این پروژه است.

**۹. چرا از `addEventListener()` استفاده می‌کنیم؟**

برای اینکه هنگام وقوع یک رویداد، مانند کلیک یا تایپ کاربر، تابع موردنظر اجرا شود.

**۱۰. `querySelector()` چه کاری انجام می‌دهد؟**

اولین عنصر منطبق با انتخابگر CSS را پیدا می‌کند. برای انتخاب همه عناصر منطبق، از `querySelectorAll()` استفاده می‌شود.

**۱۱. چرا از `try/catch` استفاده شده است؟**

برای مدیریت خطاهای احتمالی، مثلاً زمانی که عملیات ذخیره‌سازی مرورگر با مشکل مواجه می‌شود.

**۱۲. `async` و `await` چه کاربردی دارند؟**

برای نوشتن کدهای ناهمگام با ساختاری خواناتر استفاده می‌شوند؛ مثلاً زمانی که باید منتظر پاسخ یک درخواست شبکه بمانیم.

**۱۳. طراحی واکنش‌گرا چیست؟**

روشی برای تنظیم چیدمان و اندازه عناصر متناسب با ابعاد صفحه نمایش است تا سایت روی موبایل، تبلت و رایانه قابل استفاده باشد.

**۱۴. چرا در پروژه از SVG استفاده شده است؟**

برای تعریف آیکون‌های برداری که در اندازه‌های مختلف وضوح مناسبی دارند و می‌توان ظاهر آن‌ها را با CSS کنترل کرد.

**۱۵. تابع `toggleTheme()` چه کاری انجام می‌دهد؟**

پوسته فعلی را بین حالت روشن و تاریک تغییر می‌دهد، مقدار جدید را روی عنصر HTML اعمال می‌کند و انتخاب کاربر را در مرورگر ذخیره می‌کند.

**۱۶. تابع `setupReveal()` چه کاربردی دارد؟**

با استفاده از `IntersectionObserver` عناصر را هنگام ورود به محدوده قابل مشاهده شناسایی می‌کند و کلاس لازم برای نمایش تدریجی آن‌ها را اضافه می‌کند.

**۱۷. آیا این پروژه بک‌اند دارد؟**

نسخه فعلی عمدتاً فرانت‌اند است. اطلاعات ثابت در کد پروژه قرار دارند و برخی قابلیت‌ها از سرویس‌های بیرونی استفاده می‌کنند. سامانه اختصاصی رزرو، پرداخت یا حساب کاربری در آن پیاده‌سازی نشده است.

**۱۸. GitHub Pages چه کاری انجام می‌دهد؟**

فایل‌های سایت را از مخزن مشخص‌شده منتشر می‌کند و یک آدرس عمومی برای مشاهده نسخه آنلاین فراهم می‌کند.

در پروژه VakilStay، HTML، CSS و JavaScript به‌صورت مکمل استفاده شده‌اند.
